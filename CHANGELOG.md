# Changelog - Mundo Tech POS

Historial de versiones del sistema POS Mundo Tech.

## v1.0.0 - 2026-09-24
- Sistema completo de punto de venta
- Módulo de ventas con gestión de carrito y múltiples métodos de pago
- Sistema de citas con gestión de anticipos
- Módulo de comisiones para empleados
- Gestión de bodega y control de stock
- Sistema de gastos y deudas pendientes
- Galería de productos para clientes
- Sistema de usuarios con roles (Admin y Cajero)
- Panel de dashboard con estadísticas
- Historial de ventas con filtros por fecha
- Cierre de caja diario
- Sistema de licencias
